# Archive — historical / superseded documents

Everything in this folder is a **point-in-time snapshot**, not current
documentation. Some of these files predate the "AARAMBH / NST BLR" rebrand
(they still say "Newton"), some describe a `.jsx` codebase that has since
migrated to TypeScript, and the audit reports describe findings as of their
generation date — not necessarily the current state of `main`.

Kept for historical reference (git history + provenance) rather than deleted
outright. Do not treat anything here as authoritative; see the top-level
[README.md](../../README.md) and [docs/audit/](../audit/) for current status.
